# zapret-discord-youtube

Набор BAT-скриптов и конфигураций для Windows на основе [zapret](https://github.com/bol-van/zapret). Проект предназначен для проверки стратегий обработки сетевого трафика при ограничениях доступа к Discord и YouTube. Результат зависит от сети, провайдера и выбранной стратегии; универсальная работоспособность не гарантируется.

Версия публикуемых файлов: **1.10.2**.

## Быстрый старт

1. Скачайте архив из [релиза 1.10.2](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.2).
2. В свойствах архива Windows при наличии установите флажок **«Разблокировать»** и примените изменения. При распаковке через 7-Zip или PeaZip этот шаг обычно не требуется.
3. Распакуйте архив в каталог без кириллицы, пробелов и нестандартных символов, например:

   ```text
   C:\DiscordFix\
   ```

4. Запустите нужный файл `general*.bat` от имени администратора.
5. Проверьте работу Discord и YouTube. Если выбранная стратегия не помогает, остановите её и последовательно протестируйте другие доступные варианты.

Для постоянного запуска через службу используйте `service.bat`, а не отдельный `general*.bat`.

## Требования и ограничения

- Windows с правами администратора для запуска стратегий и управления службами.
- В составе используется WinDivert — системный компонент для перехвата и обработки сетевого трафика.
- Защитные программы могут помечать WinDivert как потенциально нежелательный инструмент или `Not-a-virus:RiskTool.Multi.WinDivert`. Перед запуском проверьте происхождение архива и не отключайте защиту без необходимости.
- Стратегии могут по-разному работать в разных сетях и у разных провайдеров.

Для отдельных ресурсов может потребоваться **Безопасный DNS / DNS over HTTPS**:

- в Chrome выберите конкретного поставщика в настройках безопасного DNS;
- в Firefox включите DNS через HTTPS и укажите поставщика, например `https://dns.google/dns-query`;
- в Windows 11 Secure DNS настраивается в системных параметрах;
- на роутерах Keenetic проверьте параметр **«Транзит запросов»**: его отключение может мешать работе Secure DNS на компьютере.

Подробности о WinDivert приведены в документации [zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B).

## Запуск и настройка

### Ручной запуск стратегий

`general.bat` и другие файлы `general*.bat` предназначены для ручного запуска отдельных конфигураций. Названия стратегий могут включать варианты `ALT`, `FAKE`, `SIMPLE FAKE`, `EXP` и другие.

Одна стратегия может работать лучше другой в зависимости от сети. Если первая конфигурация не дала результата, завершите её и протестируйте несколько доступных вариантов.

### Запуск через службу

`service.bat` используется для управления службой и диагностики. В меню доступны следующие пункты:

- **`Install Service`** — добавить выбранную стратегию в автозапуск Windows;
- **`Remove Services`** — удалить созданные службы и WinDivert;
- **`Check Status`** — проверить состояние служб и активную конфигурацию;
- **`Game Filter`** — настроить обработку игрового трафика через UDP/TCP на соответствующих портах;
- **`IPSet Filter`** — включить или отключить фильтрацию адресов из `ipset-all.txt`;
- **`Auto-Update Check`** — проверить доступность обновлений автоматически;
- **`Replace active fakes`** — заменить активный fake-файл другим вариантом из `bin`;
- **`Update IPSet List`** — обновить `ipset-all.txt`;
- **`Update Hosts File`** — обновить hosts для отдельных Telegram-ресурсов и голосовых подключений Discord;
- **`Check for Updates`** — вручную проверить обновления;
- **`Run Diagnostics`** — проверить распространённые причины неправильной работы;
- **`Run Tests`** — протестировать доступные стратегии.

После установки службы ручной запуск `general*.bat` для той же конфигурации не требуется.

### IPSet Filter

Режим может иметь следующие состояния:

- `none` — IP-адреса не используются для фильтрации;
- `loaded` — проверяются адреса из списка;
- `any` — под фильтрацию попадает любой IP.

После изменения параметров может потребоваться повторный запуск активной стратегии. Режим `ipset any` способен затронуть соединения, которые не должны обрабатываться, поэтому его не следует использовать постоянно.

### Тестирование

Пункт **`Run Tests`** включает:

- **Standard tests** — проверку ресурсов из `utils/targets.txt`;
- **DPI checkers** — дополнительные проверки DPI для разных сетевых условий.

## Дополнительные списки

Пользовательские домены и IP-адреса можно указывать в следующих файлах:

- `list-general-user.txt` — домены и поддомены;
- `list-exclude-user.txt` — домены для исключения;
- `ipset-all.txt` — IP-адреса и подсети;
- `ipset-exclude-user.txt` — исключения для IP-адресов и подсетей.

Файлы с суффиксом `-user` создаются автоматически при первом запуске `zapret` или `service.bat`.

## Устранение проблем

### После запуска `general*.bat` нет результата

Проверьте, появился ли процесс `winws.exe`.

- Если процесс не запускается или сразу завершается, повторите запуск от имени администратора.
- Протестируйте другую стратегию.
- Запустите `service.bat` → **`Run Diagnostics`**.
- Дополнительная информация: [issue #522](https://github.com/Flowseal/zapret-discord-youtube/issues/522).

### Ни одна стратегия не работает

Откройте командную строку от имени администратора и выполните:

```cmd
netsh winsock reset
netsh int ip reset all
netsh winhttp reset proxy
ipconfig /flushdns
```

Перезагрузите компьютер и повторите проверку нескольких стратегий.

### Не подключается Discord

1. Проверьте настройку Secure DNS.
2. Запустите `service.bat` → **`Run Diagnostics`**.
3. Очистите кэш Discord.
4. Проверьте Discord в браузере: https://discord.com/app.
5. Протестируйте другие стратегии.

Если браузерная версия работает, причина может быть связана с локальными данными приложения. Дополнительное обсуждение: [discussion #252](https://github.com/Flowseal/zapret-discord-youtube/discussions/252).

### Не открывается YouTube

Проверьте Secure DNS, смените стратегию и убедитесь, что сторонний блокировщик рекламы не влияет на загрузку сайта. Дополнительная информация: [discussion #251](https://github.com/Flowseal/zapret-discord-youtube/discussions/251).

### Не работает Telegram Web или голосовой Discord

Откройте `service.bat` → **`Update Hosts File`**. Если программа предложит обновить hosts вручную:

1. скопируйте предложенное содержимое;
2. откройте файл `hosts` с правами администратора;
3. добавьте необходимые строки;
4. сохраните файл и повторите проверку подключения.

### Не работают игры или конфликтует приложение

Сетевые схемы игр различаются, поэтому одна конфигурация подходит не всегда.

1. В `service.bat` обновите IPSet.
2. Проверьте состояние **`Game Filter`**.
3. Проверьте **`IPSet Filter`**.
4. При необходимости временно установите `Game Filter` в `disabled`, а `IPSet Filter` — в `none`.
5. Протестируйте другие стратегии.

Если игре нужны конкретные адреса, добавьте их в `ipset-all.txt`. Обсуждение проблем с отдельными играми доступно в разделе [Discussions](https://github.com/Flowseal/zapret-discord-youtube/discussions).

### Стратегия перестала работать

Сетевые условия могут измениться. Проверьте другую стратегию, запустите **`Run Diagnostics`**, обновите IPSet и hosts, а затем повторите тестирование. Описание параметров стратегий приведено в документации оригинального [zapret](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

### Полное обновление

1. Сохраните собственные изменения и пользовательские списки.
2. Перезагрузите Windows.
3. Откройте `service.bat` → **`Remove Services`**.
4. Запустите **`Run Diagnostics`**.
5. Удалите старую папку проекта.
6. Скачайте архив из раздела [Releases](https://github.com/Flowseal/zapret-discord-youtube/releases).
7. При необходимости разблокируйте архив через его свойства.
8. Распакуйте новую версию в отдельную папку.
9. Протестируйте несколько `general`-стратегий.
10. После выбора конфигурации при необходимости используйте **`Install Service`**.

### WinDivert остался в службах

Откройте `cmd` и выполните:

```cmd
driverquery | find "Divert"
```

Найдите имя соответствующей службы и выполните:

```cmd
sc stop название_службы
sc delete название_службы
```

Для Windows 7 сведения о версиях WinDivert с цифровой подписью доступны в разделе [`zapret-win-bundle/win7`](https://github.com/bol-van/zapret-win-bundle/tree/master/win7). Конфигурация WinDivert для античита описана в [windivert-hide](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

Если проблема не описана выше, создайте тему в [Issues](https://github.com/Flowseal/zapret-discord-youtube/issues), указав сеть, выбранную стратегию и результат диагностики. Для игр и нестандартных случаев используйте [Discussions](https://github.com/Flowseal/zapret-discord-youtube/discussions).
