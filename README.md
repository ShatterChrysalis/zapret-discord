# zapret Discord YouTube для Windows

Проект содержит BAT-скрипты и сетевые стратегии на базе [zapret](https://github.com/bol-van/zapret) для работы с ограничениями доступа к Discord и YouTube в Windows. Результат зависит от сети, провайдера и выбранной стратегии; универсальная работоспособность не гарантируется.

## Быстрый старт

1. Откройте страницу базового релиза [1.10.2](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.2) и скачайте опубликованный архив.
2. В свойствах архива Windows при наличии установите флажок **«Разблокировать»** и примените изменения. При распаковке через 7-Zip или PeaZip этот шаг обычно не требуется.
3. Распакуйте архив в папку без кириллицы, пробелов и нестандартных символов, например:

   ```text
   C:\DiscordFix\
   ```

4. Для ручного запуска откройте нужный `general*.bat` от имени администратора.
5. Если стратегия подходит, для работы через службу откройте `service.bat` и используйте пункт **`Install Service`**.

Перед запуском проверьте происхождение архива и исполняемых файлов. В составе используется WinDivert — системный компонент для перехвата и обработки сетевого трафика. Некоторые защитные программы могут классифицировать его как потенциально нежелательное ПО или инструмент повышенного риска. Не отключайте защиту и не добавляйте файлы в исключения без проверки источника.

## Требования и подготовка

Проект предназначен для Windows. Для запуска BAT-скриптов, установки службы и выполнения диагностических команд могут потребоваться права администратора.

Для отдельных ресурсов рекомендуется настроить **Secure DNS / DNS over HTTPS**:

- в Chrome выберите конкретного поставщика безопасного DNS вместо варианта по умолчанию;
- в Firefox включите DNS через HTTPS и укажите поставщика, например `https://dns.google/dns-query`;
- в Windows 11 настройте Secure DNS в системных параметрах;
- на роутере Keenetic проверьте параметр **«Транзит запросов»**: его отключение может мешать работе Secure DNS на компьютере.

## Ручной запуск стратегий

Файлы `general*.bat` предназначены для ручного запуска стратегий. Запускайте один выбранный вариант от имени администратора и проверьте Discord или YouTube.

Сети и провайдеры обрабатывают соединения по-разному. Если первый вариант не помогает, последовательно протестируйте доступные стратегии, включая варианты `ALT`, `FAKE`, `SIMPLE FAKE` и `EXP`. После запуска стратегии должен появиться процесс `winws.exe`.

Ручной запуск действует только пока работает запущенная стратегия. Для постоянного запуска используйте `service.bat`.

## Работа через службу

Откройте `service.bat` от имени администратора. Доступные пункты управления включают:

- **`Install Service`** — добавить выбранную стратегию в автозапуск Windows;
- **`Remove Services`** — удалить созданные службы и WinDivert;
- **`Check Status`** — проверить состояние служб и активную конфигурацию;
- **`Run Diagnostics`** — выполнить диагностику распространённых причин неправильной работы;
- **`Run Tests`** — запустить проверку доступных стратегий;
- **`Game Filter`** — настроить обработку игрового трафика через UDP/TCP на соответствующих портах;
- **`IPSet Filter`** — включить или отключить фильтрацию адресов из `ipset-all.txt`;
- **`Update IPSet List`** — обновить `ipset-all.txt`;
- **`Update Hosts File`** — обновить hosts для отдельных Telegram-ресурсов и голосовых подключений Discord;
- **`Replace active fakes`** — выбрать другой fake-файл из `bin`;
- **`Auto-Update Check`** и **`Check for Updates`** — проверить доступность обновлений.

`Install Service` используйте после выбора стратегии. Перед удалением папки проекта сначала выполните `service.bat` → **`Remove Services`**.

## IPSet Filter и тестирование

IPSet Filter может работать в трёх состояниях:

- `none` — IP-адреса не используются для фильтрации;
- `loaded` — проверяются адреса из списка;
- `any` — под фильтрацию попадает любой IP.

После изменения параметров может потребоваться повторный запуск активной стратегии. Режим `ipset any` может затрагивать соединения, которые не должны обрабатываться, поэтому не используйте его постоянно без необходимости.

Пункт **`Run Tests`** содержит:

- **Standard tests** — проверку ресурсов из `utils/targets.txt`;
- **DPI checkers** — дополнительные проверки DPI для различных сетевых условий.

## Устранение проблем

### `general*.bat` не запускается или `winws.exe` сразу завершается

Проверьте запуск от имени администратора, затем попробуйте другую стратегию. После этого откройте `service.bat` → **`Run Diagnostics`**. Дополнительное обсуждение: [#522](https://github.com/Hidefapinpoint/zapret-discord-youtube/issues/522).

### Ни одна стратегия не работает

Откройте командную строку от имени администратора и выполните:

```cmd
netsh winsock reset
netsh int ip reset all
netsh winhttp reset proxy
ipconfig /flushdns
```

Перезагрузите компьютер и повторите проверку нескольких стратегий.

### Не работает Telegram Web или голосовой Discord

Откройте `service.bat` → **`Update Hosts File`**. Если скрипт предложит обновить hosts вручную:

1. скопируйте предложенное содержимое;
2. откройте файл `hosts` с правами администратора;
3. добавьте необходимые строки и сохраните файл;
4. повторно проверьте подключение.

### Не подключается Discord

Проверьте Secure DNS, запустите `service.bat` → **`Run Diagnostics`** и протестируйте несколько стратегий. Также проверьте Discord через браузер: [discord.com/app](https://discord.com/app). Если браузерная версия работает, причина может быть связана с локальными данными приложения. Дополнительная информация: [#252](https://github.com/Hidefapinpoint/zapret-discord-youtube/discussions/252).

### Не открывается YouTube

Проверьте настройку Secure DNS, смените стратегию и убедитесь, что сторонний блокировщик рекламы не влияет на загрузку ресурса. Обсуждение: [#251](https://github.com/Hidefapinpoint/zapret-discord-youtube/discussions/251).

### Стратегия перестала работать

Проверьте другую стратегию, запустите **`Run Diagnostics`**, обновите IPSet или hosts и повторите тестирование. Параметры стратегий описаны в документации оригинального [zapret](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

### Игра или приложение конфликтует с настройками

Проверьте **`Game Filter`** и **`IPSet Filter`**. Для проверки влияния фильтрации временно установите **`Game Filter`** в `disabled`, а **`IPSet Filter`** — в `none`. Для конкретной игры можно добавить нужные IP-адреса в `ipset-all.txt`.

### WinDivert остался в службах после удаления

Выполните в `cmd`:

```cmd
driverquery | find "Divert"
```

Найдите имя службы и выполните:

```cmd
sc stop название_службы
sc delete название_службы
```

Для Windows 7 сведения о версиях WinDivert с цифровой подписью приведены в разделе [`zapret-win-bundle/win7`](https://github.com/bol-van/zapret-win-bundle/tree/master/win7). Информация о специальной конфигурации WinDivert для античита: [`windivert-hide`](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

## Пользовательские списки

Дополнительные домены и IP-адреса можно указывать в следующих файлах:

- `list-general-user.txt` — пользовательские домены и поддомены;
- `list-exclude-user.txt` — домены-исключения;
- `ipset-all.txt` — IP-адреса и подсети;
- `ipset-exclude-user.txt` — исключения для IP-адресов и подсетей.

Файлы с суффиксом `-user` создаются автоматически при первом запуске `zapret` или `service.bat`.
